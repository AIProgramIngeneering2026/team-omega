# Omega Rooms

Omega Rooms — сервис поиска и бронирования университетских аудиторий. Студент или сотрудник задаёт время встречи, число участников и нужное оборудование, а сервис показывает подходящие свободные аудитории. После выбора аудитории сервис повторно проверяет её доступность и сообщает результат бронирования.

## Проблема и пользователи

Без общего поиска приходится вручную сопоставлять вместимость аудиторий, оборудование, расписание занятий и уже созданные брони. Пользователи сервиса — студенты и сотрудники университета, которым нужна аудитория для встречи или занятия.

## Границы системы

В систему входят каталог аудиторий, поиск по времени, вместимости и оборудованию, проверка собственных броней и внешнего расписания, создание брони с повторной проверкой конфликта, получение её состояния и отмена. Внешнее расписание читается через отдельный адаптер; сервис не изменяет учебное расписание.

Не входят управление доступом в здания и аудитории, оплата, изменение расписания занятий и автоматическое подтверждение брони по решению ИИ. Пользователь сам выбирает аудиторию и подтверждает бронь.

Во втором семестре к поиску можно подключить LLM: она преобразует запрос на естественном языке в параметры поиска и объясняет, почему предложены аудитории. Проверка доступности и создание брони остаются за сервисом.
